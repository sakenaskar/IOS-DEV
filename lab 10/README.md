# Favorites Navigator

**Name:** <твое имя>
**Theme:** Movies

A UIKit app built with Storyboard only. The list screen (inside a UINavigationController with a large title) shows 20 favorite movies with a poster and a title. Tapping a row opens a detail screen via a Show segue with the large poster, title, director and year, rating (SF Symbols) and a description.
